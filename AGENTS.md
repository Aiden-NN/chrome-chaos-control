# Testing

This project has no unit tests. Do not create, restore, or run unit tests (`*.test.js`, `npm test`), and do not add a test script or test dependencies, unless explicitly asked. Verify changes with `npm run check` and the synthetic preview in `tests/preview-server.js`; `tests/browser-fixture.js` and `tests/preview-server.js` are preview tooling, not unit tests.
